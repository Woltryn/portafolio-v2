Sobre Mim

Sou José Jiménez, Desenvolvedor Backend Java com experiência no desenvolvimento e manutenção de aplicações empresariais, especialmente em ambientes que envolvem Java, Spring Boot, APIs REST, microsserviços, bancos de dados e regras de negócio complexas.

Ao longo da minha trajetória, tenho trabalhado na construção e evolução de soluções backend, participando desde a análise e implementação de funcionalidades até testes, integração entre serviços, persistência de dados e resolução de problemas técnicos. Tenho experiência com tecnologias como Java, Spring Boot, Spring Data JPA, Hibernate, SQL, Oracle, PostgreSQL, Git, Maven, JUnit e Mockito, além de conhecimentos em Apache Kafka, Docker, AWS, CI/CD e Kubernetes.

Meu foco principal é o desenvolvimento backend, mas também venho ampliando minha atuação em frontend, utilizando Angular e TypeScript, buscando compreender cada vez melhor a integração entre as diferentes camadas de uma aplicação e a construção de soluções mais completas.

Nos últimos tempos, também tenho direcionado parte dos meus estudos e projetos para Inteligência Artificial aplicada ao desenvolvimento de software, explorando LLMs, Prompt Engineering, RAG, agentes de IA e integração de modelos de linguagem com aplicações backend. Meu objetivo é entender não apenas como utilizar ferramentas de IA, mas como incorporá-las de forma prática e eficiente em sistemas reais.

Tenho como objetivo continuar evoluindo tecnicamente, aprofundando meus conhecimentos em arquitetura de software, sistemas distribuídos, cloud, mensageria, observabilidade, segurança e engenharia de software, assumindo gradualmente desafios de maior complexidade e responsabilidade técnica.

Atualmente, estou aberto a novas oportunidades como Desenvolvedor Backend Java / Java Pleno, especialmente em ambientes que utilizem Java, Spring Boot, microsserviços, APIs REST, cloud e sistemas distribuídos.
